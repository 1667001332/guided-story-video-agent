# v0.4.0 — 故事优先的生成流程

- 将完整故事提升为独立产物：生成、改写、版本记录和确认都先于剧本。
- 只有用户确认故事后才能生成剧本，剧本确认后才能进入分镜。
- 删除固定五节点大纲和固定五场剧本的 Prompt、解析与校验约束。
- 剧本场景数量由故事内容和目标时长自然决定，系统只负责分配总时长。
- 新增结构化人物、地点和视觉锚点，供剧本与后续视频连续性复用。
- 新增视觉圣经，将角色、地点、道具、色彩、光线和摄影原则变成稳定资产。
- 删除固定 5–10 镜头与固定摄影机顺序，镜头由剧本中的动作、对话、道具和状态变化决定。
- 每个镜头拆分为首帧、连续动作和结束帧 Prompt，并记录引用资产 ID。
- 视频渲染逐镜头保存进度；部分失败后保留成功镜头，再次执行时只重试失败镜头。
- 自演产物拆分为 `story.json` 与 `script.json`，会话格式升级为 schema v4。
- 保留 v0.2/v0.3 会话迁移、用户选择保护、离线兜底和付费视频确认边界。
