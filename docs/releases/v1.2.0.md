# v1.2.0 — Remove V2 offline execution runtime

自 v1.1.0 以来,仓库完成架构瘦身:移除整个 V2 离线执行运行时
(`guided_story_agent/v2/`),正式交付链路只保留 v1 的 VideoProvider 管线。

## 移除内容

- `guided_story_agent/v2/` 模块(53 个源文件):MoviePlan/FilmIR/MovieIR、
  ExecutionPlan/ExecutionBundle/ExecutionRuntime、Provider Runtime/合约、
  Revision 系统、Lineage/指纹等全部删除
- `tests/test_v2*.py`(52 个)、`tests/provider_contract/`(12 个)、
  `tests/test_public_api_surface.py`
- `prompts/v2/`(director/movie_plan 等)
- `session.py` 中的 v2 状态字段、v2 方法区段、v2 持久化键
  (约 2080 行);`cli.py` 中的 V2 交互模式与全部 v2 命令(约 870 行)
- CLI 的 `--v2` 参数与 `run_v2_interactive`

## 保留

- v1 完整链路:创意卡 → 故事 → 剧本 → 分镜/VideoJob → 真实视频
- 多 Provider 架构(`VIDEO_PROVIDER` + 注册表)、时长参数化、Web/CLI 切换
- 旧版会话(v0.2+ 的 v2.json 等)仍可加载迁移,加载逻辑不受影响

## 验证

- 测试:442 → 209(移除的全部是 v2 测试;核心测试全绿)
- ruff、compileall、全模块导入通过
- 离线全流程(start_ideation → story → script → video_job)通过

后续接入新 Provider 与 v1.1.0 完全一致:实现 `VideoProvider` 协议 →
`register_video_provider` → 设置 `VIDEO_PROVIDER`。
