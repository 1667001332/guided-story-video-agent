# v0.6.0 — 内容驱动分镜与跨镜头一致性

- 根据动作复杂度、对白、旁白、情绪停顿和叙事职责确定性分配镜头时长；每镜头为 3–15 秒，且总时长严格等于目标时长。
- 为每个镜头记录时长估算、分配理由、权重和稳定派生的 seed。
- 建立逐镜头连续性状态，跟踪地点、时段、天气、光线、人物外观、服装、伤势、位置、情绪、知识和道具。
- 同场景镜头按依赖顺序生成，提取上一镜头真实末帧，并安全暂存为下一镜头首帧。
- 复用旧任务末帧时，根据当前 `VIDEO_REFERENCE_BASE_URL` 重新生成公网 URL，不沿用 Manifest 中可能过期的地址。
- 分镜页面支持参考图上传、用途选择、镜头或资产绑定、删除与确认；视觉输入变化会使分镜确认失效。
- 人物、地点和道具参考图不会自动成为 Agnes `image`；只有明确的 `start_frame` 或上一镜头真实末帧可以作为首帧。
- 统一 `shot.narration`、TTS 和 SRT 的旁白时间轴，避免同一场景拆成多个镜头后重复旁白和字幕。
- 保留故事、剧本和分镜确认门、付费二次确认、渲染会话锁、任务 ID、成功镜头复用、`pending` 恢复和 `submission_uncertain` 防重复提交。
- 新增可续跑批量测试、安装包资源验证以及 Windows/Linux CI。

本版本的连续性链路能提供稳定输入、真实帧依赖和可复现性辅助，但视频模型最终输出的人物和场景一致性仍不能由工程层百分之百保证。
