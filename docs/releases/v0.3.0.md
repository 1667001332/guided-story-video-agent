# v0.3.0 — 低压力创意花园

## 核心变化

- 一句方向直接生成恰好 8 张非重复完整创意卡。
- 支持换一批、更多相似、AI 代选和 1–3 张融合；混合卡保留全部来源。
- 人物、冲突、转折与结局零件全部可跳过。
- 取消五轮与字段完整度门禁，最多两次点击到达完整定时草稿。
- AI 补全字段和来源明确保存；本地规则在模型输出后保护用户选择。
- Gradio 改为 2×4 多选卡片、可选聊天、场景卡草稿和简单分镜时间线。
- CLI 改为 `/pick`、`/more`、`/refresh`、`/mix`、`/draft` 等低压力命令。
- schema 升级到 v3，并只读迁移 v0.2 会话。
- Bench 新增创意多样性、重复率、选择保留率、AI 补全透明率、必要文字输入数与到达草稿点击数。

## 安全与边界

自动测试和 CI 均使用离线 Agent，不请求付费视频。真实文本必须显式使用 `--require-live-text`；真实视频还必须使用 `--render` 并二次确认费用。
