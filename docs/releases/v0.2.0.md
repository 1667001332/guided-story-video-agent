# guided-story-video-agent v0.2.0

这是引导创作主线的第二次重构版本。核心体验从固定字段盘问改为“用户主导、AI 诊断和建议”的混合共创。

## 核心能力

- 单次故事教练调用同时完成带证据事实提取、冲突检测、完整度评估、最高优先级问题和三条非强制建议。
- 可编辑故事圣经与版本历史；大纲、剧本和分镜支持修改、局部重写、撤销、重做、质量检查和确认。
- 五节点大纲、可拍摄定时剧本，以及按节奏动态生成的 5–10 镜头分镜。
- 左侧对话、右侧工作区的 Gradio 界面，以及 `guided-story-cli` 人工交互命令。
- `schema_version=2` 保存格式兼容读取 v0.1 会话。
- 扩展 Bench：问题重复率、事实保留率、冲突处理率、因果完整度、视觉锚点覆盖率和镜头多样性。
- 真实文本严格模式 `--require-live-text`，以及视频生成的显式开关和二次费用确认。

## 验证结果

- 32 项离线自动测试通过。
- Python 编译、Ruff 和 `git diff --check` 通过。
- 30、45、60 秒离线自演均精确达到目标时长，镜头数分别为 5、8、10。
- 三组自演均为 `video_requested=false`，没有调用付费视频 API。
- Gradio `Blocks.process_api` 已覆盖建议采用、故事圣经编辑、撤销、分镜确认和费用门禁。
- 人工 CLI 使用脚本输入走到 `render_ready`，未调用 Provider。

## 已知边界

- 本版本的自动验收全部离线；Agnes 真实文本和真实视频仍需使用者显式运行在线命令验证。
- 不包含账号、数据库、多人协作和商业任务队列。
- 当前提供旁白和字幕，不做角色口型同步。
- Gradio 5.x 在测试时会输出面向 6.0 的弃用提醒，不影响现有功能。
