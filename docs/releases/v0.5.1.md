# v0.5.1 — Provider 无关配置与测试交接

- 文本配置统一为 `TEXT_PROVIDER`、`TEXT_API_KEY`、`TEXT_BASE_URL`、`TEXT_MODEL`、`TEXT_TIMEOUT` 和 `TEXT_JSON_MODE`。
- 视频配置统一为 `VIDEO_PROVIDER`、`VIDEO_API_KEY`、`VIDEO_API_ROOT`、`VIDEO_MODEL` 及轮询参数。
- 保留旧版 `DEEPSEEK_*`、`AGNES_*` 环境变量兼容，新版通用变量优先。
- 明确当前文本接口要求 OpenAI `chat/completions` 兼容协议，当前视频 Provider 只实现 Agnes。
- 不支持的 Provider、缺失 Key、缺失模型 ID 和错误 JSON 模式会返回明确诊断。
- 网页真实模型状态增加 Provider 与模型名，便于外部测试确认是否发生离线兜底。
- 新增师兄 API 测试指南，覆盖安装、配置、严格文本验收、付费视频边界和反馈要求。
