# v1.3.0 — Remove legacy draft/outline flow

自 v1.2.0 以来,继续清理 v0.3 时代的"剧本草稿"旧流程
(`generate_draft` / `revise_draft` / `confirm_draft` / `build_outline` /
`build_script` 等),正式链路只保留 story → script → video 主线。

## 移除内容

- **models.py**:`DraftBundle`、`StoryOutline`、`StoryBeat`、`CreatorContribution`
  四个数据类(保留 `SourceAttribution` — 故事溯源仍在用)
- **agent.py**:协议与两处实现中的 `generate_draft` / `revise_draft` /
  `build_outline` / `build_script` / `simulate_creator`
- **session.py**:
  - 字段:`draft`、`draft_history`、`outline` 及全部重置点
  - 方法:`generate_draft` / `revise_draft` / `confirm_draft`(v0.3 兼容包装)、
    `build_outline` / `confirm_outline` / `build_script`
  - `to_dict` / `load` 中的 draft/outline 持久化键
  - undo/redo 与版本恢复中的 draft 分支
  - `_draft_from` / `_outline_from` / `_story_from_legacy_draft`
  - v0.2 会话迁移 `_load_v2` 改为直接构建 StoryDraft,不再经 DraftBundle
- **cli.py**:`/draft`、`/outline` 命令别名(原样保留 `/story`)
- **`__init__.py`**:移除 `DraftBundle`、`StoryOutline` 导出

## 保留

- v1 完整链路:创意卡 → 故事 → 剧本 → 分镜/VideoJob → 真实视频
- `chat_ideation` 与 guide-turn 辅助流程(web/CLI 仍在使用)
- 旧版会话(v0.2 / v0.3)加载迁移,不再依赖 draft 中间结构
- CLI 的 `/story`、`/script` 等主命令不受影响

## 验证

- 测试:209 全部通过(unittest 与 pytest 双跑)
- ruff、compileall、全模块导入通过
- 离线全流程 + to_dict 往返(确认不再输出 draft/outline 键)通过
