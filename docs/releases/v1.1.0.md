# v1.1.0 — Provider-neutral video pipeline

自 v1.0.1 以来,视频生成链路完成"去 Agnes 化"重构,新增多 Provider 支持,并修复了真实出片测试中发现的问题。

## 新功能

- **多视频 Provider 架构**:
  - `VideoProvider` 协议 + 注册表(`register_video_provider` / `create_video_provider`),`VIDEO_PROVIDER` 可切换到任意已注册适配器
  - 时长边界参数化:`ShotTimingProfile` 取代全部硬编码 3–15 秒公式(规划、分镜、门禁 20+ 处)
  - 分辨率/画幅、参考图、时长校验全部由 `ProviderCapabilities` 驱动
  - session 自动从所选 provider 的 capabilities 推导时长 profile,无需手动传参
- **Web / CLI 切换 Provider**:
  - Web 生成设置新增"视频 Provider"下拉框(auto + 已注册列表)
  - CLI 新增 `--video-provider NAME` 参数
- **导演 prompt 参数化**:`storyboard_director.md` 中的"3～15 秒"文案改为 `{MIN_DURATION_SECONDS}` / `{MAX_DURATION_SECONDS}` 动态注入

## 修复

- **旁白**:整片视频 prompt 默认不再包含旁白文本(避免视频模型机械念白);角色对白保留。`build_video_job(include_narration_in_prompt=True)` 可恢复旧行为
- **JSON 结构化修复器**:
  - 修复输入截断到 30K 字符,`max_tokens` 跟随主请求,避免超上下文/截断导致修复失败
  - 修复指令强制保持原任务 JSON 顶层结构
  - 模型返回空响应时自动重试一次
  - 剧本/故事连续性审查 prompt 内嵌完整输出 schema(不再引用模型看不到的文件)
- **视频下载重试**:只对网络类错误与 408/425/429/5xx 重试,404/403 等确定性错误立即失败
- 移除误提交的 `.offline-runtime-artifacts/` 离线产物跟踪

## 边界说明

- 真实视频生成仍默认使用 Agnes(`VIDEO_PROVIDER=agnes`),仅在用户确认付费后调用
- 新增 provider 需实现 `VideoProvider` 协议并在 `provider_config` 注册后方可通过 env / Web / CLI 选择
